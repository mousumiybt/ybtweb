YOBYTECH AUTOMATION — STANDALONE WEBSITE
========================================

HOW TO OPEN
1. Extract the ZIP file completely.
2. Open the extracted folder.
3. Double-click index.html.

No installation, Node.js, npm, terminal or local server is required.

IMPORTANT
- Keep index.html, style.css, script.js, favicon.svg and the assets folder together.
- Do not move index.html out of this folder.
- The website itself and its videos/images work locally.
- External YoByTech links and social links require an internet connection.
- The enquiry form opens the visitor's default email application.

EDITING
- Page content and structure: index.html
- Interactions and data: script.js
- Design, responsiveness and animations: style.css
- Images, logos and videos: assets/
